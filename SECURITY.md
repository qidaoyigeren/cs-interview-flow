# Security Policy

## Supported Versions

Only the latest release of CS Interview Flow receives security updates. Older versions are not actively patched; please upgrade to the newest release.

| Version | Supported          |
|---------|--------------------|
| latest  | :white_check_mark: |

## Reporting a Vulnerability

If you find a security vulnerability in CS Interview Flow, please report it privately so it can be fixed before public disclosure.

- **Do not** open a public GitHub issue for the vulnerability.
- Send a description of the issue, the affected version, and a minimal reproduction (if available) to the maintainer. Keep details private until a fix is released.

We will acknowledge receipt, investigate, and work with you on a coordinated disclosure timeline.

## Security Notes

The application runs on top of the RAGFlow retrieval/agent engine (Apache-2.0). Security guidance specific to that engine applies to this project as well; see the upstream [RAGFlow security policy](https://github.com/infiniflow/ragflow/security/policy) for details.
